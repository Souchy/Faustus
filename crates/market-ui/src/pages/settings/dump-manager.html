Historical datasets

poe.ninja daily prices (CC BY-SA) + GGG PC hourly exchange · Softcore challenge leagues only

No historical league data is bundled with the app. Import only the datasets you want; each import downloads and saves that league locally for future launches. Discover dumps only refreshes the catalog. After download, the selected CSV records are counted, then import progress shows processed rows / total rows, including excluded rows.

Import starts poe.ninja and GGG in parallel for the full published dataset date range (UTC days, through the last completed hour). GGG fetches only missing hours and obeys rate limits; large ranges can take hours. Older leagues may have no GGG exchange data. Each source completes independently; Browse becomes available when poe.ninja completes. Use Currency Exchange to inspect or cancel GGG imports.

Use League / dataset and As of in the header to browse saved prices. The last selected live league continues collecting automatically every 15 minutes while the app is running, including while you browse historical data.

Allflame has not been published in the catalog yet. Discover dumps again once it is available.
